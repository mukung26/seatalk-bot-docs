# Top Navigation Bar 

**Source:** https://open.seatalk.io/docs/top-navigation-bar

Top Navigation Bar is a native component provided by SeaTalk Client, it serves three functions to our user:

- Let SOP App users know where they are 

- Provide basic navigation actions 

- Provide entrance to App Menu which holds extra action buttons for an SOP App
