# Setup Test Organization

**Source:** https://open.seatalk.io/docs/set-up-test-org

While you glance over the app configuration on SeaTalk Open Platform, the Test Organization presents a new way to test your application before distributing to your target users. Let's walk through the brief guide that will help you efficiently prepare simulated data and plan out your testing during app development.

## Create Test Organization

At first, a test organization is optional of your app development and testing. However, it ensures a better quality once your app goes to public. On SeaTalk Open Platform, one test organization can be created and bind to your actual organization on SeaTalk Admin Portal. Developers from the same organization will share the access and data management responsibilities while working on the same or different apps.

![14.test_org_create_button.png](https://open.seatalk.io/apidocs/external/res/14.test_org_create_button.png)

## Management Developer Access

Before setting up dummy data inside of Test Org, you have to grant the access permission to developers. Please note only authorized developers will appear in the developer list.

![16.test_org_manage_user.png](https://open.seatalk.io/apidocs/external/res/16.test_org_manage_user.png)

## View & Access Test Organization Information

There are a few ways to manage the test organization.

- Obtain Test Organization ID

- Access Test Organization via SeaTalk Open Platform

- Access Test Organization via SeaTalk Admin Portal
